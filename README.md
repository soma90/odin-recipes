# Odin Recipes

HTML을 사용하여 요리 레시피를 소개하는 간단한 웹사이트를 제작했습니다.

## 프로젝트 소개

메인 페이지에서 레시피 페이지로 이동할 수 있는 웹사이트입니다.

각 레시피 페이지에는 요리에 대한 설명, 이미지, 재료 목록 및 조리 방법을 포함하고 있습니다.

## 사용 기술

- HTML5

## 구현 기능

- HTML 기본 문서 구조 작성
- 제목과 문단을 사용한 콘텐츠 구성
- 하이퍼링크를 이용한 페이지 간 이동
- 이미지를 활용한 콘텐츠 표시
- 순서가 없는 목록(`ul`)과 순서가 있는 목록(`ol`) 작성
- 여러 HTML 파일을 활용한 웹사이트 구성

## 프로젝트 구조

```text
odin-recipes/
├── index.html
├── img/
├── recipes/
│   ├── country-fried-squash.html
│   └── debbies-amazing-apple-bread.html
└── README.md
```

## 프로젝트를 통해 배운 점

이번 프로젝트를 통해 HTML의 기본적인 구조와 다양한 태그의 사용법을 익혔습니다.

상대 경로를 활용하여 여러 HTML 페이지를 연결하는 방법과 이미지 및 목록을 활용하여 콘텐츠를 구성하는 방법을 배웠습니다.
